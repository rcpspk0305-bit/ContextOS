# ContextOS

ContextOS is a local-first persistent intelligence layer and operating daemon that enables coding agents to continue development across sessions and models using only the minimum relevant context required for each task.

## Key Capabilities
- **AIOS Web Control Center:** Desktop-first management dashboard for agent fleets, tasks, diffs, and context budgets.
- **Token-Aware Context Engine:** Strict 4-tier context hierarchy and deterministic token budgeting preventing context bloat.
- **Persistent Project Memory:** Semantic, episodic, and architectural decision records (ADRs) with universal handoff envelopes.
- **Human Approval Gate:** Explicit controls for shell commands, file deletions, git pushes, and package management.
- **Model Context Protocol (MCP) Server:** Native MCP v2 tools and resources for Antigravity (AGY), Codex, and external clients.
- **Auditable Token Mathematics:** Provable metrics measuring candidate context vs. dispatched tokens.
